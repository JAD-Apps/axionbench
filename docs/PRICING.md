# Licensed public task pricing

`data/public-price-facts.json` is a narrow factual projection of the standard paid **text-token** tables on [Google Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing). The page explicitly grants CC BY 4.0 reuse. Attribution, licence link, retrieval time, original-byte SHA-256, exact endpoint identity and table coordinates are retained. Presentation is adapted; no source artwork, account details, raw HTML or routed provider payloads are published.

The current capture contains 11 exact endpoints. Prices join only identical authority model keys; related or newer versions receive no transferred quote. The existing 1,328 routed price rows remain excluded while their reuse terms are unsettled. This licensed source subset does not claim complete provider price coverage.

The October 2 primary recheck has SHA-256 `7ba78bbc679fc645849b973556fef12af6271889b166a052f8628bc48303d498`. It reproduces all 11 existing tariff records exactly, including cache reads/storage, thinking billed as output, the 200K prompt threshold and dated promotion expiry. The qualified original hash and original retrieval date remain unchanged. `public/data.json.pricingVerification` records the separate verification response/hash/date; private replay reparses every tariff cell before comparing facts.

BridgeBench publishes API-price information alongside its ratings, but it is not a licensed direct-provider tariff source in this product. Its Cost rating is a comparative rating, not a token price or estimated task bill. First-party confirmation of GPT-6 Luna or Claude Haiku 4.5 does not grant tariff reuse permission: without a separately qualified licensed quote, estimated cost stays unknown with a reason.

The scenario has disjoint uncached input, cached-read input and cache-write token counts. Output excludes thinking; Google bills thinking once at the output rate. A positive cache-write count is unsupported because this projection has no documented write-token tariff. Explicit cache reads require a stored context size and positive lifetime; the estimate adds stored tokens × hours × quoted USD per million token-hour / 1,000,000. Tools, taxes and non-text modalities are excluded.

Documented >200,000-prompt tiers start at 200,001 tokens and apply to the total prompt (uncached + cache read + cache write), including the output rate. Introductory tariffs expire at 2027-01-01 UTC; expired or more-than-seven-day-old captures are unsupported until refreshed. Effective dates remain unknown when not stated.

The cost/capability scatter keeps one source/suite/metric/condition panel. A value-independent rule selects the highest listed reasoning effort per model; differing effort budgets are labelled. Estimated scenario cost is distinct from historical benchmark spend and does not reproduce its token consumption. A point is nondominated only within the priced set when no point is cheaper and higher-scoring, with at least one strict improvement. Missing prices create no scatter mark and never become zero. The exact table and JSON export preserve unsupported states and both tariff and result URLs.

`python3 scripts/pricing/capture-google.py --audit-dir /private/audit` performs the real bounded capture and atomically replaces the projection only after validating permission, identities, table alignment, USD/1M units, cache/thinking semantics and every required tariff. Source HTML is stored privately by SHA-256. Refresh includes the adapter and restores last-good data on a later failure.

`npm run test:pricing` checks source-cell/rate agreement, permission/identity/tier tampering, missing versus zero, expiry, freshness, cache storage and independent hand arithmetic. Set `AXIONBENCH_PRICE_AUDIT_DIR` to the private capture directory to replay all 33 original tariff cells. `test:cost-weights` exercises the mounted controls, real displayed math, keyboard point selection, URL roundtrips, exports, reduced motion and 320–1920 px rendering. Actual receipts are ignored local files; none is a native workflow pass.

## Choosing a view and sharing a task

`/task-pricing` offers **scatter**, **costbars** and **table**. Scatter places estimated USD task cost against the benchmark's published native result unit; cost bars use estimated USD alone. The chart uses Chart.js with dark axes, keyboard inspection and reduced-motion support. It never displays hypothetical task spending as measured benchmark expenditure. The exact table and export include every measured identity, including unavailable prices; those rows have no chart mark. Result links and eligibility labels remain available in all views.

The tariff detail lists uncached input, cache read/write, output including thinking, cache storage, exact long-prompt thresholds/rates, retrieval date, unknown effective date and promotion expiration timestamp. At 200,000 prompt tokens, the captured Gemini 3.1 Pro Preview quote remains in its base tier; at 200,001 it uses the long-prompt rates. This count includes all disjoint prompt classes. A promotion becomes unavailable at its expiration timestamp, even if its retrieval is still fresh. `src/pricing/logic.ts` remains the billing implementation.

`task`, `cost-panel`, `costVersion`, `costModel` and `costView` preserve the scenario, source panel, benchmark version, inspection selection and view. Inputs, views and filters survive back/forward and hard reload. Other routes' query keys are removed. JSON export includes the scenario, calculated token/storage costs, supported or missing status, native benchmark values and units, exact result/tariff URLs, view and served data hash.

## Homepage recommendations

The homepage task picker uses current, confirmed publisher ratings for Reasoning, Front End, Back End, One Shot and Security. All three cards update from the same candidate rows when task type or token budget changes. The total budget splits into five parts uncached input and one part output, rounded to whole tokens; there is no cache or separately counted thinking in this shortcut. The full calculator remains available for a different token mix.

Economy picks the cheapest measured candidate with a usable licensed tariff. Balanced picks the highest selected capability value among candidates with usable tariffs, with lower cost breaking ties. Frontier picks the highest value among measured confirmed identities, including models with unavailable cost. These tier names describe selection rules within this limited snapshot; they do not establish universal model categories. A model can occupy multiple tiers. Missing prices cannot produce a cost-based recommendation.

BridgeBench task axes keep native publisher rating units and exact model result links. Its unpublished protocol is not reconstructed, and its overall cost/speed components are excluded from independent capability scoring. In **current independent capability** mode, the task's matching domain or explicit custom domain weights pass through the audited common-panel/family scoring rules. Every positive domain requires common current coverage; changing a weight to require an absent domain makes all three recommendations unavailable. Security has no qualified matching domain in this snapshot. The current covered tool-use comparison has two confirmed Anthropic identities and no licensed tariffs, so only its Frontier capability recommendation is available.

The optional candidate chart/table and export share the card values, units, coverage, eligibility, task costs and source links. The card links open deeper pricing with the same scenario and exact endpoint selection, plus benchmark and version pages. `taskType`, `tokens`, `benchmark`, `homeView`, `homeWeights` and custom `w` preserve homepage state without unrelated filters. Custom weights have a reset control.

`npm run test:cost-version-views` adds six-view browser checks, independent arithmetic at both exact threshold boundaries and promotion expiry, native chart/table/export parity, all task/token combinations, custom weight changes, URL restoration and fresh mobile/tablet/desktop screenshots. The prepared public source runs it as `npm run test:cost-version-views` during release verification. Screenshots and execution reports stay in ignored `test-results/`; they are local evidence, not a deployment receipt.
